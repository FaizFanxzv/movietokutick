Data Structure Lab

Lima panel untuk membedah Array, Struct, Pointer/Referensi, Sorting, dan Searching. Semua contoh yang ditampilkan berasal dari data program yang sedang berjalan.

—
Array adalah kumpulan data sejenis yang disimpan berurutan dan diakses melalui indeks yang dimulai dari 0. Array master di proyek ini bernama showtimes; setiap indeks menunjuk pada satu objek sesi penayangan. Urutan array master tidak pernah diubah oleh Bubble Sort karena pengurutan selalu dikerjakan pada salinannya.

Struct pada C/C++ menggabungkan beberapa atribut berbeda tipe menjadi satu tipe data baru. JavaScript tidak memiliki kata kunci struct, sehingga di sini digunakan objek JavaScript sebagai representasi struct — bukan deklarasi struct yang sesungguhnya. Satu objek mewakili satu sesi penayangan, dan array showtimes berisi banyak objek seperti ini.

Bentuk objek sesi (setara deklarasi struct)


    


    
    

      

        Pointer / Referensi Objek. Pada C/C++, pointer menyimpan alamat memori dan diakses
        dengan operator * serta ->, bahkan bisa dikenai aritmetika pointer.
        JavaScript tidak memberikan akses ke alamat memori mentah; yang dipegang variabel adalah
        referensi ke objek yang sama. Karena itu program ini menampilkan indeks master dan ID sesi
        sebagai penunjuk identitas data, bukan alamat memori palsu.
      

      

    


    
    

      

        Bubble Sort membandingkan dua elemen bertetangga lalu menukarnya bila urutannya salah.
        Proses diulang sampai tidak ada pertukaran lagi dalam satu putaran (early termination).
        Perbandingan dilakukan pada atribut price, dan yang diurutkan adalah
        salinan data kerja — array master tetap utuh.
